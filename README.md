# Intro Web

Small collection of teaching examples that move from static HTML to JavaScript-enhanced interactions before ending with a simple single-page experience.

## HTML demos
- **Demo 1 – Basic HTML elements** (`html/demo1-html.html`): shows headings, paragraphs, links, lists, and an embedded image with minimal inline styling for quick reference.
- **Demo 2 – Two-column layout** (`html/demo2-columns.html`): introduces simple CSS layout by floating two equal-width columns that each contain headings, links, and paragraphs.
- **Demo 3 – JS + CSS toggles** (`html/demo3-js-css.*`): pairs a stylesheet and script so clicking any `<h1>` toggles a highlight class, illustrating DOM selection, event listeners, and shared CSS.

## Single-page app
- **`single-page-app/`**: demonstrates a menu-driven single-page layout; p5.js powers the JavaScript that switches visible sections, while Skeleton CSS plus a custom stylesheet handle the responsive grid layout.
